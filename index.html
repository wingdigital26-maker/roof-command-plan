How one agent serves every roofer

  1. Shared playbooks

    What works for roofing lives in one shared folder that every job can read.

  2. A wall around each roofer

    Each job loads one roofer's vault and database, so nothing crosses between clients.

  3. Hosted apps

    Roofers' apps stay online even if the Mac mini restarts. The mini does the background thinking.

  4. One monitor over all

    The fleet monitor finds problems across clients before a roofer does.

Models to test

  1. Fast sorting

    gpt-oss-20b. Light enough to run all day for filtering, watching and logs.

  2. Planning and writing

    Qwen3.6 35B on 32 GB or more, or Gemma 4 26B on 24 GB or more.

  3. Fixing code

    Qwen3-Coder or Qwen3.8 27B. It only wakes up when something breaks.

  4. Nimbus voice

    Gemma 4 26B to start. Voice needs fast replies, so speed decides this one.

These are starting ideas. Each model gets tested on our real work, and any of them can be swapped later.

The vault

  1. Obsidian stays

    Plain files people can read and edit, with no lock-in.

  2. Add a search index

    A local index helps each job find the right notes as the vault grows.

  3. Add version history

    Git keeps every change, so a bad edit can be rolled back.

  4. Keep facts in the database

    Homes, leads and sends live in the database. The vault holds judgment.
